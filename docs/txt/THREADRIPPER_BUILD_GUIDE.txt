CPU: AMD Threadripper 3960X (24 cores / 48 threads)
----------------------------------------------------------------------
Price: $500-700 used, $1400+ new (if you can find it)
Why this one:
  ✓ 24 cores = perfect for 16-thread pipeline + headroom
  ✓ 3.8 GHz base, 4.5 GHz boost (good single-thread too)
  ✓ 128 PCIe lanes (overkill but future-proof)
  ✓ Zen 2 architecture (same as your Ryzen 4700U)
  ✓ TDP: 280W (manageable cooling)

Alternative considerations:
  • 3970X (32 cores): +$400, only 33% faster for your workload
  • 3990X (64 cores): +$1000, overkill unless running 2+ searches
  • 5000-series TR: Hard to find, expensive, minimal benefit

Verdict: 3960X is the sweet spot

SECTION 3: ASSEMBLY GUIDE
======================================================================

TOOLS NEEDED
----------------------------------------------------------------------
• Phillips screwdriver (magnetic tip helps)
• Thermal paste (Noctua NT-H1 or Arctic MX-5)
• Cable ties
• Anti-static wrist strap (optional but recommended)
• Flashlight (case interiors are dark)
• Patience

WORKSPACE
----------------------------------------------------------------------
• Clean, flat surface
• Good lighting
• Anti-static mat or cardboard (not carpet!)
• Keep motherboard box for initial build/testing

BUILD ORDER (Do it RIGHT)
----------------------------------------------------------------------

STEP 1: Unbox and inventory
  □ Check all parts received
  □ Read motherboard manual (seriously!)
  □ Identify all cables, screws, standoffs

STEP 2: Install CPU (OUTSIDE case)
  □ Place motherboard on box/mat
  □ Release CPU socket lever
  □ Align CPU triangle with socket triangle
  □ Drop CPU in (NEVER force it!)
  □ Close lever (may require moderate force)
  □ Inspect: CPU should sit flat, pins not visible

STEP 3: Install RAM (OUTSIDE case)
  □ Check manual for slot population order
  □ Usually: A2, B2, C2, D2 (2nd slot of each channel)
  □ Open clips on both sides of slot
  □ Align RAM notch with socket key
  □ Press down firmly until clips snap closed
  □ RAM should be level, fully seated

STEP 4: Install M.2 SSD (OUTSIDE case)
  □ Locate M.2 slot (usually near CPU)
  □ Remove heatsink if present
  □ Insert SSD at 30° angle
  □ Press down flat
  □ Screw in standoff
  □ Replace heatsink

STEP 5: Test POST (BEFORE case installation)
  □ Connect 24-pin ATX power
  □ Connect 8-pin CPU power
  □ Connect monitor to motherboard video out
  □ Connect keyboard
  □ SHORT power pins with screwdriver (or use button if board has one)
  □ System should POST (display BIOS screen)
  □ Enter BIOS, verify:
    - CPU detected (should show 3960X)
    - All RAM detected (should show 128GB)
    - SSD detected
  □ Shutdown (hold power pins short)

  If no POST:
    - Check RAM fully seated (reseat firmly)
    - Check CPU power cable connected
    - Check monitor cable in motherboard (not GPU slot)
    - Clear CMOS (jumper or button)

STEP 6: Install motherboard in case
  □ Install I/O shield (snaps in from inside)
  □ Install standoffs in case (match motherboard holes)
  □ Carefully place motherboard (align I/O shield)
  □ Screw in motherboard (don't overtighten!)
  □ All screws should be in, check for loose standoffs

STEP 7: Install cooler
  □ Remove plastic cover from CPU
  □ Apply thermal paste (pea-sized dot in center)
  □ Mount Noctua TR4 backplate (see manual!)
  □ Place cooler on CPU
  □ Screw down in X pattern (little at a time)
  □ Connect fan to CPU_FAN header
  □ Connect pump if AIO

STEP 8: Install PSU
  □ Place PSU in case (fan facing DOWN if bottom vent exists)
  □ Screw in 4 corners
  □ Route cables behind motherboard tray

STEP 9: Connect all cables
  □ 24-pin ATX to motherboard
  □ 8-pin (4+4) CPU power to motherboard
  □ SATA power to... nothing (no drives!)
  □ Front panel headers (power, reset, LEDs) - see manual!
  □ Case fans to motherboard or PSU

STEP 10: Cable management
  □ Route cables behind motherboard
  □ Use velcro ties (reusable)
  □ Airflow > aesthetics
  □ Just make it not terrible

STEP 11: Final POST
  □ Connect monitor, keyboard
  □ Power on
  □ Should POST immediately
  □ Enter BIOS


SECTION 4: BIOS CONFIGURATION
======================================================================

CRITICAL SETTINGS FOR PRIME HUNTING
----------------------------------------------------------------------

Boot into BIOS (usually DEL or F2 key during POST)

1. ENABLE XMP/DOCP (RAM speed)
----------------------------------------------------------------------
   AI Tweaker / Extreme Tweaker → DOCP/XMP Profile 1
   This sets RAM to rated speed (3200MHz)

2. SET CPU TO ALL-CORE PERFORMANCE
----------------------------------------------------------------------
   Advanced → AMD CBS → SMU Common Options
   → Performance → Disable Precision Boost Overdrive
   → Set all cores to base clock (3.8 GHz)
   
   Why? Consistent performance, lower temps, 24/7 stable

3. DISABLE UNNECESSARY FEATURES
----------------------------------------------------------------------
   Advanced → AMD CBS → NBIO Common Options
   → Disable Onboard graphics (if option exists)
   
   Advanced → Onboard Devices Configuration
   → Disable HD Audio (no sound needed)
   → Disable WiFi/Bluetooth
   
   Boot → Disable Fast Boot (better for Linux)

4. ENABLE VIRTUALIZATION (optional, for future)
----------------------------------------------------------------------
   Advanced → CPU Configuration → SVM Mode = Enabled
   (Allows VMs, Docker, etc.)

5. SET FAN CURVES
----------------------------------------------------------------------
   Monitor → Fan Control
   → CPU Fan: Ramp from 40% at 50°C to 100% at 80°C
   → Case Fans: Constant 60% (quiet enough, good airflow)

6. SAVE & EXIT
----------------------------------------------------------------------
   Save changes and reboot


SECTION 5: LINUX INSTALLATION & OPTIMIZATION
======================================================================

RECOMMENDED DISTRO: Fedora Workstation (or your preference)
----------------------------------------------------------------------
Why Fedora:
  ✓ Up-to-date kernel (good TR support)
  ✓ You're already using it
  ✓ GCC/GMP in repos
  ✓ Works out of the box

Alternatives: Ubuntu 24.04, Debian 12, Arch (if you're brave)

INSTALLATION
----------------------------------------------------------------------

1. Create USB installer
   - Download Fedora ISO
   - Use Fedora Media Writer or dd
   - Boot from USB (F11 or F12 during POST)

2. Install Fedora
   - Default options are fine
   - Partition: Use entire disk, LVM
   - Create user account
   - Set hostname: threadripper01 (or whatever)

3. First boot updates
   sudo dnf update -y
   sudo dnf install gcc gcc-c++ gmp-devel make vim git htop -y

4. Verify CPU detection
   lscpu | grep "Model name"
   # Should show: AMD Ryzen Threadripper 3960X
   
   lscpu | grep "^CPU(s):"
   # Should show: 48 (24 cores × 2 threads)

5. Verify RAM detection
   free -h
   # Should show: ~125GB available

6. Install monitoring tools
   sudo dnf install lm_sensors
   sudo sensors-detect (answer yes to all)
   sensors
   # Should show CPU temp, ~40-50°C idle

PERFORMANCE TUNING
----------------------------------------------------------------------

1. Disable CPU frequency scaling (max performance)
   echo performance | sudo tee /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor

   To make permanent:
   sudo vim /etc/default/grub
   # Add to GRUB_CMDLINE_LINUX:
   # intel_pstate=disable amd_pstate=disable
   sudo grub2-mkconfig -o /boot/grub2/grub.cfg
   sudo reboot

2. Increase file descriptor limits
   sudo vim /etc/security/limits.conf
   # Add:
   * soft nofile 65536
   * hard nofile 65536

3. Disable swap (you have 128GB RAM!)
   sudo swapoff -a
   sudo vim /etc/fstab
   # Comment out swap line

4. Set process priority for CVPipe
   nice -n -10 ./generate_candidates 10000000000000000000000

COMPILE FLAGS FOR THREADRIPPER
----------------------------------------------------------------------

Update your Makefile:

CC = gcc
CFLAGS = -O3 -march=znver2 -mtune=znver2 -fopenmp -Wall
LDFLAGS = -lgmp

Test compilation:
cd ~/cvpipe
make clean
make

Should compile without warnings


SECTION 6: BENCHMARKING & VALIDATION
======================================================================

STRESS TEST (verify stability)
----------------------------------------------------------------------

1. CPU stress test (24 hours recommended)
   sudo dnf install stress-ng
   stress-ng --cpu 48 --timeout 86400s --metrics
   
   Monitor temps:
   watch -n 1 sensors
   # Should stay under 85°C

2. Memory test
   sudo dnf install memtest86+
   # Or run from GRUB menu
   # Let it run 4+ passes (8+ hours)

3. Prime hunting stress test
   cd ~/cvpipe
   make test
   # Should complete successfully
   
   Then run overnight:
   nohup make run > test.log 2>&1 &
   tail -f test.log

BENCHMARK AGAINST YOUR RYZEN
----------------------------------------------------------------------

Run identical search on both systems:

Ryzen 4700U (your baseline):
  ./generate_candidates 10000000000000000000
  time make run
  # Note: elapsed time

Threadripper 3960X:
  ./generate_candidates 10000000000000000000
  time make run
  # Should be ~3x faster!

Expected speedup:
  • Stage 1 (generate): 2-3x faster
  • Stage 2 (filter): 2-3x faster
  • Stage 3 (emirp): 2-3x faster

VERIFY RESULTS MATCH
----------------------------------------------------------------------

Compare .dat files:
  diff ryzen_emirps.dat threadripper_emirps.dat
  # Should be identical!

If results differ:
  ✗ Check GMP version (should be same)
  ✗ Check compiler flags
  ✗ Verify RAM with memtest86+

PARALLEL SEARCH STRATEGIES
----------------------------------------------------------------------

Strategy 1: Split range
----------------------------------------------------------------------
  threadripper01: Search 10^23 to 5×10^23
  threadripper02: Search 5×10^23 to 10^24
  
  2x speed for same range!

Strategy 2: Different targets
----------------------------------------------------------------------
  threadripper01: Deep search (10^24)
  threadripper02: Verification search (10^20 to 10^21)
  
  One explores, one validates

Strategy 3: Simultaneous ranges
----------------------------------------------------------------------
  Both search same range, compare results
  Ultimate verification!

DISTRIBUTED COMPUTING (Advanced)
----------------------------------------------------------------------

Option A: Manual coordination
  • Split candidate generation manually
  • Each system processes own range
  • Merge results at end

Option B: GNU Parallel
  sudo dnf install parallel
  # Generate candidates centrally
  # Distribute filtering across both systems

Option C: MPI (Message Passing Interface)
  • Rewrite code with OpenMPI
  • Unified job across both systems
  • Complex but powerful

Start with Option A (simplest)


SECTION 8: TROUBLESHOOTING
======================================================================

PROBLEM: System won't POST
----------------------------------------------------------------------
□ Check CPU power cable (8-pin connected?)
□ Check RAM fully seated (push HARD)
□ Try one stick of RAM in slot A2
□ Clear CMOS (jumper or button)
□ Remove all drives, boot with just CPU/RAM

PROBLEM: System crashes under load
----------------------------------------------------------------------
□ Check temps (sensors)
□ Reseat cooler (remount with new paste)
□ Disable XMP/DOCP (run RAM at 2666MHz)
□ Update BIOS to latest
□ Test RAM with memtest86+

PROBLEM: Slow performance
----------------------------------------------------------------------
□ Check governor: cat /sys/devices/system/cpu/cpu0/cpufreq/scaling_governor
□ Should say "performance" not "powersave"
□ Check CPU isn't throttling: lscpu | grep MHz
□ Should show ~3800 MHz

PROBLEM: Results don't match Ryzen
----------------------------------------------------------------------
□ Check GMP version: gmp --version
□ Recompile with exact same flags
□ Verify input data identical
□ Check for RAM errors (memtest86+)

PROBLEM: High temps (>85°C sustained)
----------------------------------------------------------------------
□ Remount cooler (reapply paste)
□ Check fan spinning (should be audible)
□ Improve case airflow (add fans)
□ Reduce voltage slightly in BIOS

PROBLEM: Intermittent crashes
----------------------------------------------------------------------
□ Update BIOS
□ Run memtest86+ (24 hours)
□ Check PSU cables fully seated
□ Try different RAM slots
□ RMA if under warranty
