  DESIGN PRINCIPLES
═══════════════════════════════════════════════════════════════════════════════

  ✓ Separation of Concerns
    - Pure string functions isolated from GMP
    - No unnecessary dependencies

  ✓ Modularity
    - Easy to add new functions
    - ar r libname.a newfile.o

  ✓ Reusability
    - libstrarith.a works in ANY C project
    - libgmparith.a for GMP-based projects

  ✓ Zero Overhead
    - Static linking - only used functions included
    - Optimized with -O3

  ✓ Thread Safety
    - str_reverse_tls() uses __thread storage
    - All GMP functions thread-safe when used properly
